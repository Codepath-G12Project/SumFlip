# App Idea Brainstorming

## 1. Initial Brainstorming Ideas

For our group project, we considered six app ideas that would be fun, interactive, and useful to different types of users. We wanted to create an app that would be enjoyable to use while also giving us the opportunity to practice what we have learned about iOS development using SwiftUI.

### Idea 1: SumFlip — Math Card Game

SumFlip is an interactive math card game where players flip hidden number cards to find two numbers that produce a target number. For example, if the target is 5, a player could flip cards containing 2 and 3 because 2 + 3 = 5.

The game would support addition, subtraction, multiplication, and division. Players could choose different difficulty levels, race against a timer, earn points, and compete with others through a leaderboard or multiplayer challenges.


### Idea 2: Math Rush — Timed Math Challenge

Math Rush is a fast-paced math quiz game where players solve arithmetic problems before time runs out. Players receive points for correct answers and can build streaks by answering multiple questions correctly.


### Idea 3: Memory Match — Card Matching Game

Memory Match is a classic memory game where players flip cards to find matching pairs. The goal is to remember the locations of previously revealed cards and match every pair using as few attempts as possible.


### Idea 4: Quiz Battle — Trivia Competition

Quiz Battle is a trivia app where players answer questions from different categories, such as science, history, sports, and entertainment. Players earn points for correct answers and can compete with friends.


### Idea 5: FlashLearn — Interactive Study Flashcards

FlashLearn is a study app that allows users to create and review digital flashcards. Students can organize cards by subject and test their knowledge using different study modes.


### Idea 6: Number Puzzle — Logic and Number Game

Number Puzzle is a puzzle game where players use numbers and mathematical operations to complete challenges. Players must think strategically to solve puzzles and advance through increasingly difficult levels.





## 2. Evaluation of Our Top Three Ideas

After reviewing the six ideas, we selected SumFlip, Math Rush, and Memory Match as our top three choices.

We evaluated them based on originality, entertainment value, usefulness, technical difficulty, and the features we could realistically implement using SwiftUI.

### Idea 1: SumFlip — Math Card Game

SumFlip is our strongest idea because it combines entertainment and education. It also provides opportunities to practice several iOS development concepts, including state management, user interaction, navigation, and animations. We can build the basic card-matching game first and add more advanced features as development progresses.


### Idea 2: Math Rush — Timed Math Challenge

Math Rush would be a practical and manageable project. However, we felt it was less creative than SumFlip because the gameplay mainly involves answering traditional math questions.


### Idea 3: Memory Match — Card Matching Game

Memory Match is a good option because it is interactive and achievable. However, SumFlip builds on the card-flipping mechanic while adding mathematical challenges, making the experience more unique.





## 3. Final App Idea Chosen

After comparing our top three ideas, we selected SumFlip as our final group project.

We chose SumFlip because it offers a balance between creativity, educational value, and technical challenge.

The card-flipping mechanic makes the app more interactive than a traditional math quiz. Supporting multiple mathematical operations and difficulty levels will also help keep the gameplay interesting.

From a development perspective, SumFlip will allow our group to practice important SwiftUI concepts, such as creating reusable views, managing game state, handling user interactions, displaying timers, implementing animations, and navigating between screens.

We also believe the project is achievable within the course timeline if we prioritize the core game mechanics before implementing more advanced features.
